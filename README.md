# Frank's Land Report — Sales Page

The sales page for **The Home Buyer's Secret Files** and its three standalone
guides, live at [frankslandreport.com](https://frankslandreport.com).

Plain HTML, CSS and JavaScript with no build step — open `index.html` in a
browser and it works.

| | |
|---|---|
| `index.html` | The page itself |
| `css/styles.css` | All styling; the `THEME` block at the top holds the palette |
| `js/main.js` | Sticky bar, FAQ accordion, promo countdown |
| `assets/` | Channel avatar, banner, product covers |
| `terms.html` `privacy.html` `refund.html` | Legal pages |
| `LAUNCH-GUIDE.md` | How to put this online on your own hosting and domain |

## Putting it online

See **[LAUNCH-GUIDE.md](LAUNCH-GUIDE.md)** for the full walkthrough. The short
version: download the ZIP, unzip it, and drag the folder that contains
`index.html` into [Netlify](https://app.netlify.com/drop).
